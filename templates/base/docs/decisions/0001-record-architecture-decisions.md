# 1. Record architecture decisions

- Status: accepted
- Date: YYYY-MM-DD

## Context

Decisions get lost in chat threads and commit messages. New contributors (human or agent) need to know why the system is the way it is.

## Decision

Each significant decision gets a short numbered record in this folder: context, decision, consequences. Records are not edited after acceptance; a later record supersedes an earlier one.

## Consequences

Changing a past decision means writing a new record that references it.
