# Licensing

Atelier is proprietary software. The source is public so you can read it, check how it treats your code and your
accounts, and try it before you commit. Everything else needs a licence. The legal text is in [LICENSE](../LICENSE).

## What you can do today, without a licence

| | |
|---|---|
| Read the source on GitHub | Yes |
| Evaluate Atelier on one machine for 30 days | Yes |
| Use it beyond that, at work or at home | Needs a licence |
| Copy, modify, redistribute or sell it | Needs a licence |
| Host it or offer it as a service to others | Needs a licence |

## Getting a licence

Open a **[licence request](https://github.com/Medamineelkhattabi/atelier/issues/new?template=licence-request.yml)** and tell the author:

- who will use Atelier: you alone, a team, or a company;
- on how many machines;
- which agents you plan to run (Claude Code, Gemini CLI, Codex, GitHub Copilot, Cursor...);
- anything you need besides the licence: help setting it up, custom team members, or integration with your tools.

The issue is public, so keep private details out of it. The author will reply there and move the conversation to a
private channel.

## Good to know

- **Your agents, your accounts.** A licence covers Atelier only. Each agent you connect runs on your own plan with its
  vendor, under that vendor's terms.
- **No usage metering.** Atelier doesn't phone home. It works fully on your machine.
- **Third-party components** used by Atelier (FastAPI, React and others) stay under their own open-source licences.
