# Contributing

Atelier is proprietary, so code contributions are accepted only under a written agreement with the author. Bug
reports and ideas are very welcome:

- **Found a bug?** Open a [bug report](https://github.com/Medamineelkhattabi/atelier/issues/new?template=bug-report.yml).
- **Missing something?** Open a [feature request](https://github.com/Medamineelkhattabi/atelier/issues/new?template=feature-request.yml).
- **Want to use Atelier?** See [docs/LICENSING.md](docs/LICENSING.md).
- **Security issue?** Follow [SECURITY.md](SECURITY.md); please don't open a public issue with details.

If you have an agreement and are working on the code, read [AGENTS.md](AGENTS.md) first: it gives the commands, the
hard rules and the conventions, for people and coding agents alike.
